# @pet-fit/engine — 공개 표시 계층 (shim)

비공개 모노레포의 엔진 패키지 중 **공개 가능한 두 파일만** 담은 대체 패키지다.

- `src/types.ts` — 도메인 타입 (런타임 코드 없음)
- `src/format.ts` — 표시 계층: 판정 결과 → 한국어 문구 (라벨·포맷 함수만)

판정 룰(여유분 매트릭스·밴드 경계·역추정 변환)은 **서버 전용 비공개 자산**이라
이 레포에 없다. 클라이언트는 설계상 그 코드를 import 할 수 없고, 그 경계는
`scripts/guard-engine-boundary.mjs` 가 빌드에서 기계적으로 강제한다.
