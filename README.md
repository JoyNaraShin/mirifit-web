# 미리핏 (mirifit) — 반려견 옷 사이즈, 입혀보고 사세요

반려견 실측 치수(또는 "전에 산 옷이 어땠는지"에 대한 답)로 옷의 **부위별 핏을
구매 전에 판정**해 주는 웹 서비스의 클라이언트 레포입니다.

**라이브 데모**: https://mirifit.vercel.app
(현재 배포본은 실측 입력 → 옷 선택 → 부위별 판정의 T1 동선. 이전 옷 기반
역추정(T2) 동선은 개발 완료 상태로 다음 배포에 포함됩니다.)

> 이 레포는 비공개 모노레포에서 클라이언트 앱만 커밋 히스토리째 분리한
> 공개본입니다. 판정 엔진(여유분 매트릭스·판정 룰·역추정 알고리즘)과 서버
> 함수는 비공개입니다 — 아래 [아키텍처](#아키텍처-엔진은-서버-전용) 참조.

## 스택

- **React 19 + Vite 6 + TypeScript** (strict, `noUncheckedIndexedAccess`)
- **TanStack Query 5** — 서버 상태. 클라이언트 소유 원본(localStorage 프로필)은
  쿼리로 감싸지 않고 `useSyncExternalStore` 로 구독 — 캐시 의미론이 맞지 않는
  값에 캐시 도구를 쓰지 않습니다
- **Tailwind CSS v4** (`@theme` 토큰) + 자체 UI 프리미티브 (`src/components/ui`)
  — 외부 UI 라이브러리 없음
- **React Router 7** — 뒤로가기·재진입 루프·딥링크가 있는 동선이라 URL 이 상태의
  정본입니다

## 아키텍처 — 엔진은 서버 전용

판정 룰(원단×체급 여유분 매트릭스, 판정 밴드, 역추정 변환)은 이 서비스의 핵심
자산이라 **클라이언트 번들에 절대 실리지 않습니다**.

```
[비공개 모노레포]                         [이 레포 (공개)]
packages/engine  ──판정·역추정 룰──┐
api/*            ──Vercel 함수────┤ HTTP(JSON) ──→  src/*  (화면·상태·표시)
                                  │                 engine-display/  (타입·라벨 shim)
                                  └── 치수 원본·시드 DB (비노출)
```

- 클라이언트는 `@pet-fit/engine/display`(라벨·포맷 함수·타입)만 import 할 수
  있습니다. 이 레포의 `engine-display/` 는 그 공개 가능 계층만 담은 shim 입니다.
- 경계는 규칙이 아니라 **빌드가 강제**합니다 — `scripts/guard-engine-boundary.mjs`:
  - `src` 모드: 소스에서 엔진 코어 import 를 잡습니다 (`import type` 만 허용)
  - `dist` 모드: 번들에서 엔진 내부 전용 캐너리 토큰을 잡습니다 (minify 생존 키)
- API 응답도 화이트리스트 투영입니다 — 예: `ease`(옷 치수 − 실측)를 응답에서
  제거해, 자기 실측을 아는 클라이언트가 사이즈표를 역산하는 경로를 막습니다.

## 화면 동선

```
S1 시작 ─→ (줄자 없음) S2 이전 옷 응답 ─→ 역추정(서버) ─┐
      └→ (줄자 있음) S3 직접 실측 ────────────────────┤
                                                      ↓
                              S4 옷 선택 ─→ S5 부위별 핏 맵 결과
                                            └→ 정확도 루프(S2/S3 재진입)
```

- 추정(T2) 판정에는 **불확실성 병기가 의무**입니다 — "적정 (±2.5cm — 이전 옷
  기준 추정)" 처럼, 근거가 약한 판정이 확정처럼 보이지 않게 합니다
- 원단 미표기 상품(실측 표본에서 표기율 0%)은 니트/우븐 양쪽 가정으로 판정하고
  갈림을 그대로 노출합니다 — "판정 갈림: 적정/여유"

## 접근성

- 판정은 색만으로 전달하지 않습니다 — 핏 맵 SVG 는 보조 표현이고 텍스트 판정
  행이 정본, SVG 에도 부위 텍스트 라벨 + `role="img"` 요약을 병행합니다
- 라이트/다크 대비를 수치로 검증했습니다 — 라벨 텍스트 ≥4.5:1, 존 경계 ≥3:1
  (verdict 색 라벨이 라이트 모드에서 2.3:1까지 떨어지는 것을 실측으로 잡아
  ink 토큰 + 경계선으로 보정)
- 칩 그룹·카드 선택은 네이티브 라디오로 — 키보드 규약을 손으로 재구현하지
  않습니다. 제출 차단은 버튼 비활성 대신 사유 노출 (비활성 버튼은 탭 순서에서
  사라져 스크린리더가 이유에 도달할 수 없습니다)

## 로컬 실행

```bash
pnpm install
PETFIT_API_TARGET=https://mirifit-api.vercel.app pnpm dev   # /api 를 라이브로 프록시
pnpm build    # 경계 가드(src) → tsc → vite build → 경계 가드(dist)
```

서버 함수가 비공개라 로컬 API 는 없습니다 — 개발 서버는 `/api` 를 라이브
배포로 프록시합니다.
